> Date: 2026-05-09 | Status: approved

## 概述

在 boss-tool 现有工作流基础上，新增 AI 自动生成个性化话术 + 自动发送功能。

## AI 话术生成 (engine/messenger.py)

### 输入
- 候选人姓名、简历文本、沟通职位、消息预览

### Prompt 模板
```
你是专业HR。根据候选人信息生成个性化打招呼消息：

候选人：{name}
职位：{position}
简历摘要：{resume}
对方消息：{preview}

要求：
- 2-3句话，80-150字
- 提及对方具体经历或技能
- 表达招聘诚意
- 引导发送附件简历
- 自然口语化，不用表情包
```

### 输出
返回生成的消息文本字符串

## 自动沟通工作流

### 新增 API

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/automessage/start` | POST | 启动自动沟通 |
| `/api/automessage/stop` | POST | 停止自动沟通 |
| `/api/automessage/status` | GET | 获取自动沟通状态 |

### 工作流步骤
① 提取聊天列表
② 去重（基于姓名+日期，7天内不重复发送）
③ 点击对话 → 查看简历 → AI 生成消息 → 自动发送
④ 等待间隔（默认15秒）
⑤ 达到上限或列表结束 → 停止

### 安全控制
- DAILY_LIMIT: 30条/天
- MIN_INTERVAL: 15秒
- 已发送记录保存在 data/sent_records.json
- 支持随时暂停

## 前端

在主页增加「自动沟通」面板：
