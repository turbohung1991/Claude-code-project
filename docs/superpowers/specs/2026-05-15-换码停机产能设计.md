# 换码停机产能设计

## 目标

在生产计划表中新增「产品换码停机」产能因素，使排产更准确。

## 当前状态

- 产能只考虑节假日和周日休息（通过「设置排产」表 + 各产线 Row2 班次标记）
- 日产能公式：`=IF(单/双, 单班/双班产能, 0) - 已排产量`
- 未考虑同一产线切换不同规格产品时的换码停机损失

## 设计方案

### 1. 新增「换码设置」配置表

| 字段 | 说明 |
|------|------|
| 产线 | 产线名称（对应工作表名） |
| 换码损失(双班) | 双班模式下每次换码损失的片数 |
| 换码损失(单班) | 单班模式下每次换码损失的片数 |

- 初始使用模拟数据填充所有14条产线
- 后续替换为正式数据时只修改此表即可

### 2. 换码检测逻辑

- 对每个日期列（M→BP），扫描当天有排产量（>0）的订单行
- 提取其规格（G列），计算不同规格种数
- 换码次数 = 不同规格数 - 1（0或负数视为0）
- 换码损失 = 换码次数 × 对应产线单次换码损失

### 3. 产线表改动

- 在 Row 2（班次行）下方插入新行：每日换码损失
- 新行公式：`=MAX(0, 去重规格数 - 1) * VLOOKUP(产线名, 换码设置, 班次对应列)`
- 原产能公式改为：`=IF(单/双, 对应产能 - 换码损失, 0) - 已排产量`
- 涉及 14 个产线工作表

### 4. 扩展预留

- 配置表保留「换码类型」字段，待正式数据到位后可细化到尺寸/片数/包数维度
- 当前 v1 版本按完整规格字符串做去重比对
