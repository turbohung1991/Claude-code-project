# GPT-Image-2 图像生成

通过 ToAPIs gpt-image-2 模型生成图像。终端 CLI 调用，生成后自动打开图片。

## 工具

```
~/bin/python3.14 "/Users/admin/claude code project/image_gen.py" [选项] "<提示词>"
```

## 参数

| 参数 | 说明 | 可选值 | 默认 |
|---|---|---|---|
| `--size` | 宽高比 | `1:1`, `3:2`, `2:3`, `4:3`, `3:4`, `5:4`, `4:5`, `16:9`, `9:16`, `2:1`, `1:2`, `21:9`, `9:21` | `1:1` |
| `--resolution` | 分辨率 | `1K`, `2K`, `4K` | `1K` |
| `--reference` | 参考图路径（可多次指定） | 本地图片文件路径 | 无 |
| `--output` | 保存路径 | 任意路径 | 自动命名 |

## 文生图流程

1. 确认提示词和参数（用户未指定则默认 `1:1` + `1K`）
2. 根据场景推荐比例：头像→1:1，手机壁纸→9:16，桌面壁纸→16:9，海报→2:3/3:2
3. 执行命令，等待 10-30 秒，终端显示实时进度
4. 图片自动保存到当前目录并用系统默认程序打开

## 图生图流程（用户提供参考图时）

1. 先确认用户是否已提供图片文件路径，若用户粘贴了图片但没有路径，引导用户将图片保存到磁盘
2. 使用 `--reference <图片路径>` 指定参考图，可多次指定多张参考图
3. 脚本会自动上传图片到 ToAPIs 获取 URL，然后调用 gpt-image-2 图生图
4. 其余流程同文生图

## 模型

接口已固定使用 `"model": "gpt-image-2"`，无需每次指定。

## 注意

- 图片 URL 有效 24 小时
- 出现 `content_policy_violation` 或上游失败时，提示用户精简描述后重试
- 不要修改 image_gen.py
- 不允许对输入的生图提示词作任何修改
- 生成完毕后，优先使用本地终端显示图片。另外报告文件路径、分辨率和生成耗时
